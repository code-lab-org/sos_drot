# sos_drot
Dynamic Reward-Based Observation Tasking (DROT) Framework for Earth Observation Systems
Implementation and analysis code accompanying the paper:


Banafsheh, H., Wrzesien, M. L., Ramachandran, D., Vuyovich, C. M., & Grogan, P. T.
A Dynamic Reward-Based Optimization Framework for Satellite Task Planning in Earth Observation: Application to Snow Mass Observation.

Available at SSRN: https://ssrn.com/abstract=6142417
DOI: https://doi.org/10.2139/ssrn.6142417


Overview

This repository contains the implementation of the Dynamic Reward-Based Observation Tasking (DROT) framework, a scalable optimization approach for prioritizing taskable satellite observations in distributed Earth observation systems. The framework is demonstrated for snow water equivalent (SWE) observation over the Missouri River Basin.
